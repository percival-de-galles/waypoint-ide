# Security

Please do not report security problems in Waypoint through public issues. Contact the maintainers privately instead.

Waypoint is a fork of Visual Studio Code. If a problem also affects upstream VS Code, report it to Microsoft as well, following [their security policy](https://aka.ms/SECURITY.md).

Each agent runs through its own CLI, under its own sign-in. Report problems in an agent to that agent's maintainers.
